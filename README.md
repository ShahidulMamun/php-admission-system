# Admission System 
A simple Admission System built with Raw PHP, MySQL, HTML, CSS, and JavaScript. The project allows users to manage and organize questions through a web-based interface.

# Tech Stack
  * Raw PHP
  * MySQL
  * HTML5
  * CSS3
  * JavaScript

# Installation

  1. Clone the repository
     https://github.com/ShahidulMamun/php-admission-system.git
  2. Move the project to your local server (htdocs or www).
  3. Create a MySQL database.
  4. Import the SQL file.
  5. Update the database credentials in the configuration file.
  6. Open the project in your browser.
